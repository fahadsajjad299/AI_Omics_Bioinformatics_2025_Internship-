## Getting Started

### Prerequisites
- R (version 3.6 or higher)
- RStudio (recommended)
- Git (for cloning repository)

### Installation

```bash
# Clone the repository
git clone https://github.com/fahadsajjad299/AI-and-Omics-Research-Internship-2025.git

# Navigate to directory
cd AI-and-Omics-Research-Internship-2025
```

### Required R Libraries

```R
# Install required packages
install.packages(c(
  "GEOquery",
  "limma",
  "clusterProfiler",
  "Boruta",
  "caret",
  "randomForest",
  "e1071",
  "neuralnet",
  "ggplot2",
  "tidyverse"
))
```

### Running the Scripts

```R
# Set working directory
setwd("~/AI-and-Omics-Research-Internship-2025")

# Run Module I scripts
source("Codes/Module_I_R_Programming/R_Introduction.R")
source("Codes/Module_I_R_Programming/R_Syntax.R")
source("Codes/Module_I_R_Programming/R_Functions.R")

# Run Module II scripts
source("Codes/Module_II_Microarray_Data_Analysis/QC_&_Normaliztion.R")
source("Codes/Module_II_Microarray_Data_Analysis/Differential_Gene_Expressions.R")
source("Codes/Module_II_Microarray_Data_Analysis/Functional_Enrichemt_Analysis.R")

# Run Module III scripts
source("Codes/Module_III_Machine_Learning/Machine_Learning.R")
```
